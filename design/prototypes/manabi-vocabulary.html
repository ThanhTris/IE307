Tự động phân tách từ vựng, cách đọc và giải nghĩa vào các mặt thẻ.

Tải lên file .csv hoặc .xlsx Chạm vào đây để chọn tệp từ thiết bị
Hỗ trợ phân cách bằng Khoảng trắng, Tab, Dấu phẩy (,), Gạch ngang (-)...
Cách lấy thẻ từ Quizlet:
1. Mở học phần Quizlet → Bấm ... → Chọn Xuất (Export).
2. Chọn ngăn cách bằng Tab → Bấm Sao chép văn bản → Dán vào ô bên dưới.
Hệ thống tự động nhận diện Thuật ngữ (Front) và Định nghĩa (Back).
Cách lấy thẻ từ Anki:
1. Mở Anki → File (Tệp) → Export... (Xuất...) → Chọn định dạng Notes in Plain Text (.txt).
2. Mở file .txt hoặc copy toàn bộ nội dung dán vào ô bên dưới (tự động lọc bỏ các dòng comment #).
Hỗ trợ 2 đến 4 cột chuẩn Anki (Mặt trước, Cách đọc, Mặt sau, Ví dụ).
