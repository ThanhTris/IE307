Markdown frontmatter là nguồn trạng thái. Khi đổi trạng thái chuyển file đúng thư mục và sửa status; không copy thành hai task. Owner/reviewer là đề xuất tới khi nhận việc. Task chỉ mở khóa dependency sau khi có quyết định review có ngày.

GitHub Assignees mang nhãn `assignment:proposed` là gợi ý, không phải giao việc bắt buộc. Người nhận cuối cùng xác nhận và đổi sang `assignment:accepted`; sau đó đồng bộ Markdown. Xem [danh sách issue](../docs/project/GITHUB_TASKS.md).
