[24 task triển khai dự kiến](backlog/MASTER_BACKLOG.md), [task nền đang review](review/GM-00.md), [template](templates/TASK_TEMPLATE.md).

Markdown frontmatter là nguồn trạng thái. Khi đổi trạng thái chuyển file đúng thư mục và sửa status; không copy thành hai task. Owner/reviewer là đề xuất tới khi nhận việc. Task review chưa mở khóa dependency.

GitHub Assignees mang nhãn `assignment:proposed` là gợi ý, không phải giao việc bắt buộc. Người nhận cuối cùng xác nhận và đổi sang `assignment:accepted`; sau đó đồng bộ Markdown. Xem [danh sách issue](../docs/project/GITHUB_TASKS.md).
