Xem [lộ trình và bảng mã cũ–mới](../docs/project/TASK_RENUMBERING.md); previous_ids chỉ tra lịch sử, không là dependency. Các cặp parallel_with được làm phần độc lập song song sau start gate riêng.

Markdown frontmatter/task map là nguồn scope, artifact và danh sách dependency; Done trên [Project #2](https://github.com/users/ThanhTris/projects/2) là nguồn nghiệm thu dependency theo ADR-011. Owner/proposed_assignee đã đồng bộ theo phân công Project ngày 2026-10-11; lịch và Deadline xem trên Project, không nhân bản lịch 4 tuần ở repo. Status Markdown có thể chậm hơn Project, không cần chuyển folder để mở task tiếp. start_dependencies chặn viết phần độc lập; merge_dependencies chặn tích hợp/merge và cộng thêm start deps. parallel_with khác owner, không quan hệ start, được có quan hệ merge. Trước merge dùng --gate merge --base-ref origin/main sau cập nhật ref và kiểm PR/commit/test thật. Nếu cập nhật status Markdown thì move file đúng folder, không copy; done vẫn cần review evidence thật. Chạy --write-docs để retarget link và sinh bảng, rồi validator/--check-docs. Không tự Approved/Done.

`python scripts/task_readiness.py --task GM-XX`: kiểm trước làm; BLOCKED không bắt đầu. `--all`: xem tổng. `--write-docs`: sinh lại indexes sau đổi task; `--check-docs`: CI kiểm drift. Checker đọc Project để kiểm Done, không tự đồng bộ assignee, Deadline hoặc dependency vào file; cần cập nhật task/task map khi chủ dự án đổi phân công hoặc gate.

Assignee được giao không tự là xác nhận nhận việc; assignment_status giữ nguyên tới khi có xác nhận phù hợp. Trí review/merge cuối cho mọi task, kể cả task Trí trực tiếp viết; không cần chỉ định người kiểm độc lập theo ADR-013. Approved cần review thực tế của Trí/ngày/evidence thật, không chỉ folder done hoặc merge PR. [Project mapping](project-gate.json) chứa issue hiện hành; [GitHub mapping cũ](../docs/project/GITHUB_TASKS.md) chỉ giữ lịch sử. Việc đổi owner hiện hành không viết lại tác giả/evidence đã có. GM-01 hiện chưa có item trên Project; không suy Issue Closed hoặc Approved local thay Project Done để vượt gate.
