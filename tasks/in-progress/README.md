# Đang thực hiện

Các file `PM-*` còn trong `main` thuộc baseline Memo cũ, không là task Manabi đang thực hiện. Xem [nguồn task Manabi](../../docs/project/START_HERE.md) trên nhánh triển khai trước khi nhận hoặc cập nhật việc.

Chỉ đặt task đã có owner, reviewer, ngày dự kiến và acceptance criteria. Cập nhật progress, blocker và evidence ngay trong task file.
