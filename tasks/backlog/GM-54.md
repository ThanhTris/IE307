# GM-54 — Cấu hình phát hành Android/iOS, cổng phiên bản và Places

[Issue #190](https://github.com/ThanhTris/IE307/issues/190). Thuộc phạm vi đăng store đầu tiên (`release:v1`), xem [RELEASE_V1_SCOPE](../../docs/project/RELEASE_V1_SCOPE.md). Trang thực hiện, Trí review.

`app.config.ts` mới khai báo Android với version 0.1.0; chưa có cấu hình iOS, chưa có cách buộc cập nhật bản cũ, và Places/bản đồ cần chỉnh để dùng được trong phạm vi miễn phí.

## Phạm vi

- `app.config.ts`: version 1.0.0, `ios.bundleIdentifier`, mô tả quyền iOS, `ITSAppUsesNonExemptEncryption`, privacy manifest, icon/splash/adaptive icon đủ kích thước, platforms gồm android và ios. Chỉ xin camera, vị trí khi dùng và thông báo; không chạy nền.
- Cổng phiên bản tối thiểu: migration nhỏ tạo cấu hình chỉ đọc (RPC công khai), app so version và hiện màn "Cần cập nhật" kèm liên kết store; không đọc được thì vẫn cho dùng.
- Ẩn mục thông báo đẩy khi chưa cấu hình EAS project ID. Thay bản đồ nhúng `google.com/maps?...&output=embed` bằng Maps Embed API chính thức hoặc nút mở Google Maps. Gửi header ứng dụng cho Places để giới hạn key theo app và thêm cache giảm số lượt gọi.
- `mobile/eas.json` (một file dùng chung cho hai store): profile `development`, `preview` (bản release candidate cài nội bộ), `production-android` (AAB, tự tăng versionCode) và `production-ios` (tự tăng buildNumber). Khóa Places là public key nên đặt qua biến môi trường EAS theo từng profile, mỗi nền tảng một key riêng; không ghi giá trị key vào repo. `ios.supportsTablet` mặc định `false` (chỉ iPhone, không phải nộp ảnh iPad); hỏi Trí nếu muốn hỗ trợ iPad.
