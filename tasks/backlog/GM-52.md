# GM-52 — Dựng Supabase staging và production

[Issue #188](https://github.com/ThanhTris/IE307/issues/188). Thuộc phạm vi đăng store đầu tiên (`release:v1`), xem [RELEASE_V1_SCOPE](../../docs/project/RELEASE_V1_SCOPE.md). Trí thực hiện, Trí review.

Mọi lượt kiểm đến giờ dùng QA local. `supabase/config.toml` không áp dụng cho project hosted: đăng nhập ẩn danh, SMTP, Realtime và cờ `allow_new_sessions` phải cấu hình riêng.

## Phạm vi

- Hai project (staging, production) trên gói miễn phí. Áp migration bằng ledger, không chèn bản cũ hơn bản đã áp.
- Workflow keepalive (gọi nhẹ mỗi 2–3 ngày; GitHub tắt lịch chạy sau khoảng 60 ngày không có hoạt động trong repo công khai) và workflow backup hằng tuần.
- Runbook deploy, rollback, đổi key; kiểm ledger và định nghĩa hàm so với `main`, không chỉ health.

## Phạm vi và AC

- [ ] `db push` lên staging thành công; ledger và định nghĩa hàm khớp `main`.
- [ ] Cấu hình dashboard: đăng nhập ẩn danh, email kèm SMTP, Realtime, giới hạn tốc độ, `allow_new_sessions` bật đúng quy trình. Bí mật chỉ nằm trong dashboard hoặc GitHub secrets.
- [ ] Lịch tick GM-48 chạy; catalogue GM-51 đã nạp; Edge Function xóa tài khoản GM-49 đã deploy.
- [ ] Smoke HTTP trên staging: khách → tạo phòng → vào → bầu cả hai vòng → kết quả → xóa tài khoản.
- [ ] Không có `service_role` hay secret trong repo hay app; publishable key đặt qua EAS secrets.
- [ ] Production chỉ nhận bản đã qua staging.
