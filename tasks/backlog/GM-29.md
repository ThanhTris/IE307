## Acceptance criteria

- [ ] Lazy load/capability guard để Expo Go vẫn mở UI; thông báo hướng dẫn dev build đúng giới hạn.
- [ ] Remote push kiểm thiết bị/credential thật khi có, denied vẫn inbox; không lấy local notification làm evidence remote.
- [ ] Tap event fetch server, không tin payload cấp quyền/join; duplicate/expired/deleted user safe.
- [ ] Không log token/raw votes; package thay đổi coordinate owner tooling.
- [ ] Đầu vào/đầu ra và cách kiểm được ghi trong HANDOFF.md; reviewer đối chiếu revision thật.

- Loại kiểm: `expo-native`.
- Công cụ: Expo Go startup + development build thiết bị Android + API runner.
- Điểm mở/gọi: Inbox/native push permission → register device → nhận remote push → tap/refetch.
