# GM-55 — Bộ test case, truy vết và xuất báo cáo

[Issue #191](https://github.com/ThanhTris/IE307/issues/191). Thuộc phạm vi đăng store đầu tiên (`release:v1`), xem [RELEASE_V1_SCOPE](../../docs/project/RELEASE_V1_SCOPE.md). Trí thực hiện, Trí review.

Repo có nhiều test tự động (mobile, Python, SQL, HTTP) nhưng chưa có bộ test case có mã, bảng truy vết yêu cầu → test case → test và bảng kết quả để trình bày trong báo cáo.

## Phạm vi

- `docs/testing/`: kế hoạch test, baseline yêu cầu (REQ), khoảng 280 test case theo 15 module (nguồn JSON), bảng truy vết, báo cáo kết quả.
- `scripts/test_cases.py`: kiểm schema, sinh Markdown, xuất Excel `.xlsx` (chỉ dùng thư viện chuẩn Python), tự nhận tag `TC-XXX-NNN` trong tên test.

## Phạm vi và AC

- [ ] `python scripts/test_cases.py --check` đạt: ID không trùng, REQ tồn tại, đường dẫn và tên test trong `automation` có thật, mọi REQ P0 có ít nhất một ca.
- [ ] Mỗi ca có tiền điều kiện, dữ liệu, các bước, kết quả mong đợi, tầng test, môi trường và liên kết test tự động hoặc `manual`.
- [ ] File Excel mở được trong Excel với các sheet Test cases, Traceability, Summary, Defects.
- [ ] Baseline REQ nêu rõ phần FR cũ đã lỗi thời (8 → 20 người, quán/GPS → dish-only, ready theo ADR-028) để báo cáo không mâu thuẫn.
- [ ] Test unittest sinh lại file và khớp bản đã commit; CI chạy `--check`.
