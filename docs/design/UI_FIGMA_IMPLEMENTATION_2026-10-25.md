# UI theo Figma đã chốt — giao việc ngày 2026-10-25

> Phạm vi bổ sung thiết kế hiện hành theo [xác nhận của Trí sau hai đợt](UI_SCOPE_CONFIRMED_2026-10-25.md); không tự mở thêm gap từ các đề xuất cuối đã được loại khỏi phạm vi.

> Cập nhật sau khi duyệt đề xuất: U01–U05 đã được áp dụng lên Figma, gồm hai state mới và sửa các màn hiện có; xem [bàn giao cập nhật](UI_APPROVED_UPDATES_2026-10-25.md). Các phát hiện cũ bên dưới là lịch sử trước khi sửa; không dùng để báo thiếu lại. Present và runtime vẫn theo phạm vi kiểm riêng.

Theo yêu cầu mới của Trí, bắt đầu giao lại phần UI theo [final handoff](UI_FINAL_HANDOFF_2026-10-25.md). Hướng dẫn tạm hoãn FE ngày 2026-10-25 đã được thay cho phạm vi 20 task bên dưới. BE/Data tiếp tục phần việc riêng. Đây là cập nhật yêu cầu/AC, không triển khai app hoặc nghiệm thu runtime.

Baseline khi lập: main `9aa9696be62010351bb81ff4e3bcd19cd2f4050f`, sau revert PR #134. Không khôi phục implementation của PR đã revert bằng việc sửa task. Contract B và runtime/version producer phải được bàn giao riêng; thiết kế đã có không chứng minh API đã có.

## Nguồn dùng để thực hiện

1. Chỉ dẫn hiện hành của Trí và luật sản phẩm đã chốt.
2. Final handoff + frame/component trong Figma, đối chiếu [task map máy đọc](UI_FIGMA_TASK_MAP.json).
3. Task AC và contract/version/HANDOFF producer đã được duyệt; code hiện hành là baseline cần sửa.
4. Prototype HTML, ảnh cũ, router QA và storyboard là tham chiếu lịch sử. Không dùng chúng để hạ yêu cầu Figma.

Figma mang mục tiêu visual, contract mang dữ liệu/hành vi; nếu mâu thuẫn thì ghi rõ node/field/scenario và hỏi Trí trước khi tự đổi luật.

## Quy trình để AI lấy đúng thiết kế

- Đọc task, final handoff và `UI_FIGMA_TASK_MAP.json`; xác minh fileKey/nodeId qua Figma MCP, không đoán ID.
- Dùng skill `figma-design-to-code` trước `get_design_context`, giữ screenshot làm đích visual. Gọi context cho đúng frame/state, lưu node/revision/thời điểm; nếu response sparse thì đọc node con liên quan. Đọc Code Connect nếu có và reuse đúng component phù hợp; map ở đây chưa tự chứng nhận Code Connect hoặc code hiện tại đã khớp Figma.
- Đọc component/variables/text styles. Theme hiện có `GCD / UI colors` mode Light, font Inter. Xanh trang trí #46C34F không dùng làm nền chữ cần đọc; primary action dùng token contrast thực tế. Không tự lấy lại palette cam từ code cũ.
- Download asset theo hướng dẫn Figma, giữ provenance/quyền sử dụng và geometry. Không dùng temporary asset URL ở runtime. Ảnh món từ API có thể thiếu; hiển thị fallback, không suy dữ liệu thật từ artwork minh họa.
- Chuyển reference React/web sang React Native theo feature/domain/data boundaries; không cài Tailwind hoặc chụp nguyên màn làm asset.
- Nếu gap chưa có frame: cập nhật Figma bằng skill Figma, ghi node/revision và review trước bàn giao; không thay đổi core đã chốt ngoài scope.
