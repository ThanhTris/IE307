## Cách thử trên điện thoại

`192.168.1.104`; điện thoại cần cùng mạng Wi-Fi. Trong Expo Go hỗ trợ SDK57 nhập:

```text
exp://192.168.1.104:8081/--/gm13/result
```

Hoặc từ Home → Công cụ kiểm thử → Xem cấu trúc ứng dụng →
Mở kết quả và chưa đồng thuận · GM-13. Đường này đã qua route integration test.

Nếu cần tự chạy lại tại root repo:

```powershell
cd mobile
# Dùng IPv4 Wi-Fi hiện tại của máy; không lấy IP Radmin/VMware hoặc localhost.
$env:REACT_NATIVE_PACKAGER_HOSTNAME = '192.168.1.104'
npm start -- --clear --port 8081
```
