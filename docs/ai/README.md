# Dùng AI hỗ trợ phát triển

Đọc [AGENTS](../../AGENTS.md) và [prompt template](TASK_PROMPT_TEMPLATE.md). AI hỗ trợ spec/code/test, reviewer con người quyết định nghiệm thu. Không đưa phiếu thật, token, session hoặc thông tin nhạy cảm vào prompt.

AI trong quy trình phát triển khác tính năng AI trong sản phẩm. MVP không cần gọi model; P2 chỉ theo [extension spec](../specs/EXTENSIONS_SPEC.md).
