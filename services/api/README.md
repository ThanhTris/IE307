# API và Edge Functions

Backend ưu tiên Supabase để giảm thời gian vận hành trong đồ án. Thư mục này chứa Edge Functions hoặc adapter API không phù hợp với PostgREST/RPC mặc định, ví dụ nhập dữ liệu phức tạp, đồng bộ theo lô và xuất backup.

Mọi endpoint phải có contract, auth rule, validation, error model và test tương ứng.
